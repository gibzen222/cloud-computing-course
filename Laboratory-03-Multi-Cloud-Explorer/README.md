# Laboratory 03 – Multi-Cloud Explorer

## Introduction

This laboratory activity explores three major cloud computing platforms: Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP).

## Objectives

* Learn the basic features of AWS, Azure, and GCP.
* Compare the services offered by the three cloud platforms.
* Identify the advantages and disadvantages of each platform.
* Recommend suitable cloud platforms for different clients and needs.

## Cloud Platforms

### Amazon Web Services (AWS)

AWS is a cloud computing platform that provides services such as computing, storage, databases, networking, and security.

### Microsoft Azure

Microsoft Azure is a cloud platform that provides computing, storage, networking, database, and other cloud services for businesses and organizations.

### Google Cloud Platform (GCP)

GCP is Google's cloud computing platform that provides services for computing, storage, databases, networking, data analytics, and artificial intelligence.
