# AWS, Microsoft Azure, and Google Cloud Comparison

## Checkpoint 3 — Major Cloud Platform Comparison

The following table compares several important characteristics of Amazon Web Services, Microsoft Azure, and Google Cloud.

| Category | Amazon Web Services (AWS) | Microsoft Azure | Google Cloud Platform (GCP) |
|---|---|---|---|
| Launch Year | 2006 | 2010 | 2008* |
| Compute Service | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage Service | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Networking Service | Amazon VPC | Azure Virtual Network | Google Cloud VPC |
| Identity Service | AWS IAM | Microsoft Entra ID | Google Cloud IAM |
| Primary Strength | Broad cloud service portfolio and mature infrastructure | Microsoft ecosystem and hybrid-cloud integration | Data analytics, AI/ML, and Kubernetes |
| Ideal Organizations | Startups, enterprises, global applications, and organizations requiring many cloud service options | Organizations heavily using Microsoft technologies and hybrid infrastructure | Organizations focusing on cloud-native applications, data, AI/ML, and Kubernetes |

> *Google's cloud platform developed from early Google cloud services including Google App Engine, introduced in 2008. The modern Google Cloud portfolio expanded substantially afterward.

# Analysis Questions

## 1. Which cloud provider offers the broadest range of services?

For this comparison, I would choose **Amazon Web Services (AWS)** as the provider with the broadest overall cloud service portfolio. AWS provides services across computing, storage, databases, networking, security, analytics, artificial intelligence, containers, Internet of Things, serverless computing, and many other areas.

## 2. Which provider best integrates with Microsoft technologies?

**Microsoft Azure** is the strongest choice for organizations already using Microsoft technologies. Azure works closely with technologies and services associated with Windows Server, Microsoft identity solutions, enterprise Microsoft applications, and hybrid cloud environments.

## 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

For an organization prioritizing AI and Kubernetes, I would select **Google Cloud** because it provides Vertex AI for machine-learning workloads and Google Kubernetes Engine for managed Kubernetes deployments. Google has also played an important role in the development of Kubernetes, making GCP a particularly attractive environment for cloud-native container workloads.

## 4. Which cloud platform would you personally choose and why?

I would personally choose **Google Cloud Platform** for a project focused on cloud-native development because of its strong artificial intelligence, data, and Kubernetes capabilities. However, my final choice for a real organization would still depend on the organization's budget, existing technology, employee expertise, performance requirements, and business objectives.

# Checkpoint 5 — Equivalent Cloud Services

The following table identifies comparable services available from AWS, Microsoft Azure, and Google Cloud.

| Service Category | AWS | Microsoft Azure | Google Cloud |
|---|---|---|---|
| Virtual Machine | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Object Storage | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Identity Management | AWS IAM | Microsoft Entra ID | Cloud IAM |
| SQL Database | Amazon RDS | Azure SQL Database | Cloud SQL |
| Kubernetes | Amazon EKS | Azure Kubernetes Service (AKS) | Google Kubernetes Engine (GKE) |

## Service Comparison Notes

Although the services in the table perform similar general functions, they are not necessarily identical. Each cloud provider uses different architectures, pricing models, integrations, management tools, and capabilities.

For example, Amazon EC2, Azure Virtual Machines, and Compute Engine all provide virtual machine infrastructure, while Amazon EKS, Azure Kubernetes Service, and Google Kubernetes Engine provide managed Kubernetes environments.
