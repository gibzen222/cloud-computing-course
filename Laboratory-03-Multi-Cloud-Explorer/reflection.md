# Mission 3 Reflection

## Multi-Cloud Explorer

Among AWS, Microsoft Azure, and Google Cloud, **Google Cloud Platform impressed me the most** because of its strong focus on data analytics, artificial intelligence, and Kubernetes. Services such as Vertex AI and Google Kubernetes Engine show how the platform supports modern application development and machine learning workloads. I also found its organization of regions and zones easy to understand.

The three cloud platforms are similar because they all provide the main building blocks needed by organizations: virtual machines, object storage, networking, identity management, managed databases, and Kubernetes services. They also provide web-based management consoles and global infrastructure so users can deploy resources in different geographic locations.

Business requirements strongly influence cloud platform selection because there is no single provider that is best for every situation. A company must consider its existing technologies, budget, expected growth, performance requirements, staff skills, security needs, and geographic coverage. For example, an organization that already relies heavily on Windows Server, Microsoft 365, and Active Directory may benefit from Azure, while an AI-focused organization may prefer Google Cloud services. AWS may be attractive when a business wants a very broad service portfolio and extensive global deployment options.

Acting as a Cloud Solutions Consultant taught me to compare technology based on the client's problem rather than simply choosing the most popular platform. I learned to map business requirements to specific cloud services and explain why a recommendation makes technical and practical sense.

My GitHub Cloud Computing Portfolio also improved because Laboratory 03 adds organized research, comparison tables, client recommendations, screenshots, Linux investigation results, and a reflection. The repository now provides clearer evidence of my progress in cloud computing and gives me practice creating professional technical documentation in Markdown.
