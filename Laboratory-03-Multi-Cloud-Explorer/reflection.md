# Reflection

This laboratory activity helped me understand the differences between AWS, Microsoft Azure, and Google Cloud Platform. I learned that each cloud platform provides different services and has its own strengths.

I learned that AWS offers many different cloud services and is useful for many types of businesses. Azure is a good option for organizations that use Microsoft products and technologies. GCP is useful for data analytics, artificial intelligence, and machine learning.

I also learned that choosing a cloud platform depends on the needs of the client. Factors such as budget, security, scalability, existing technology, and technical requirements should be considered before choosing a platform.

Overall, this laboratory activity improved my understanding of cloud computing and showed me how cloud platforms can help businesses and organizations manage their applications and data.
