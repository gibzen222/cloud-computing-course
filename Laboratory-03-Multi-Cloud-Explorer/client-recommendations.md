# Cloud Platform Recommendation Challenge

## Client A – Startup Company

**Recommended Platform: Amazon Web Services (AWS)**

AWS is recommended because it offers a wide range of services that can support a startup as it grows. The company can begin with smaller cloud resources to control costs and scale them as the mobile application gains more users. AWS also provides managed services that can reduce the amount of infrastructure the startup needs to maintain. This makes AWS a flexible choice for a growing company with a limited budget.

**Recommended Services:**

* Amazon EC2 – for running application servers
* Amazon S3 – for storing application files and data
* Amazon RDS – for managing the application's relational database
* AWS Lambda – for running application functions without managing servers

---

## Client B – University

**Recommended Platform: Microsoft Azure**

Microsoft Azure is the best choice because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure integrates well with Microsoft's existing technologies, which can make cloud migration easier to manage. The university can also use Microsoft identity services to manage users and access to cloud resources. This can help the university maintain a consistent environment while gradually moving services to the cloud.

**Recommended Services:**

* Azure Virtual Machines – for migrating Windows Server workloads
* Microsoft Entra ID – for identity and access management
* Azure SQL Database – for cloud-based database applications
* Azure Blob Storage – for storing files, documents, and backups

---

## Client C – AI Research Company

**Recommended Platform: Google Cloud Platform (GCP)**

Google Cloud Platform is recommended because it provides strong services for Artificial Intelligence and Machine Learning workloads. The company can use powerful computing resources to train and run AI models. GCP also provides specialized AI and machine learning tools that can help researchers develop and deploy applications. Its data and analytics services can also support research involving large datasets.

**Recommended Services:**

* Google Compute Engine – for high-performance computing workloads
* Google Kubernetes Engine (GKE) – for deploying and managing containerized applications
* Vertex AI – for developing, training, and deploying AI and machine learning models
* Cloud Storage – for storing large datasets and research files

---

## Client D – Global E-Commerce Company

**Recommended Platform: Amazon Web Services (AWS)**

AWS is recommended because the company needs highly available infrastructure that can serve customers around the world. AWS provides global infrastructure and services that can automatically scale resources based on demand. This is important for an e-commerce company that may experience sudden increases in website traffic during promotions or holidays. AWS also provides services for load balancing, databases, storage, and application deployment.

**Recommended Services:**

* Amazon EC2 – for running web and application servers
* Elastic Load Balancing – for distributing traffic across application servers
* Amazon RDS – for managing the e-commerce database
* Amazon S3 – for storing product images, files, and other data
* Amazon CloudFront – for delivering content to customers around the world
